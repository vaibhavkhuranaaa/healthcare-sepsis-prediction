# Scope

## Included

- Deterministic synthetic cohort and held-out evaluation
- Constant baseline and calibrated challenger comparison
- Calibration, threshold burden, and leakage evidence
- Synthetic score, timeline, and driver API
- Responsive, accessible research dashboard
- Reproducible local and CI verification

## Excluded

- Clinical-device status or validation
- Diagnosis, treatment, triage, monitoring, or care guidance
- Patient-facing or clinician-facing workflows
- MIMIC redistribution or public patient-level artifacts
- Production reliability, subgroup safety, transportability, or utility claims
